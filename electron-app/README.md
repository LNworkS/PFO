# 智能记账 - Windows 桌面版

基于 Electron 打包的个人财务管理桌面应用。

## 快速开始

### 1. 环境要求
- Windows 10 / 11 (64位)
- Node.js 18 或更高版本（已安装在 `C:\Users\Nanil\AppData\Local\nodejs`）

### 2. 安装依赖
双击运行 **`安装依赖.bat`**
> 首次安装需要下载 Electron，约 100MB，请耐心等待

### 3. 运行开发版
双击运行 **`运行开发版.bat`**
> 开发模式下可以直接使用和测试所有功能

### 4. 打包应用
双击运行 **`打包应用.bat`**
> 打包完成后会在 `dist\智能记账-win32-x64\` 目录生成 `智能记账.exe`
> 直接双击即可运行，也可以整个文件夹复制到其他电脑使用

## 功能特性

- 🔒 **本地加密存储**：密码加盐哈希 + AES-256-GCM 数据加密，数据存储在用户目录
- 💰 **收支记账**：支持自定义分类、多账户管理、转账
- 📊 **统计报表**：分类占比图、收支趋势图
- 📈 **银行利率**：内置 13 家银行官方挂牌利率数据库，自动每日计息
- 🎯 **预算管理**：分类预算 + 总预算，超支预警
- 💾 **数据导出/导入**：加密文件备份，多端同步

## 数据存储位置

应用数据存储在系统用户目录下：
```
C:\Users\你的用户名\AppData\Roaming\smart-accounting\data.json
```

数据全程 AES-256-GCM 加密，只有密码可以解密。

## 常见问题

**Q: 安装依赖很慢或失败？**
A: 已配置国内镜像源（npmmirror），如仍失败请检查网络或关闭代理后重试。

**Q: SmartScreen 提示未知发布者？**
A: 这是正常的，因为没有购买代码签名证书。点击「更多信息」→「仍要运行」即可。

**Q: 如何创建桌面快捷方式？**
A: 找到 `dist\智能记账-win32-x64\智能记账.exe`，右键 → 发送到 → 桌面快捷方式。

**Q: 如何卸载？**
A: 直接删除整个应用文件夹即可，数据保留在用户目录。如需完全清除，再删除 `%AppData%\smart-accounting` 目录。
